## ترتيب القراءة

1. اقرأ ADMIN-0 لتفهم الحالة الحالية وما هو موجود فعليًا وما هو مقترح.
2. راجع سجل قرارات PO وتأكد من عدم خلطها بحالة التنفيذ.
3. اقرأ ADM-1-plan؛ هذه خطة مراجعة فقط، وليست إذنًا بكتابة كود.
4. لا تبدأ ADM-1 أو أي Backend implementation إلا بعد دمج DOC-01 وموافقة PO المكتوبة على الخطة.

## قواعد الإثبات

- [GH] حقيقة تحققت مباشرة من GitHub أو ملفات الفرع المحدد.
- [PO] قرار صريح من مالك المنتج في المحادثة بتاريخ 22 نوفمبر 2026.
- [PROPOSED] تصميم أو تنفيذ مقترح لم يُنفذ بعد.
- [UNVERIFIED] لا يوجد دليل كافٍ؛ لا يجوز تقديمه كحقيقة.

GitHub هو المرجع لحالة الفروع والـ PRs والـ CI. قرارات PO هي المرجع لنطاق المنتج والموافقة. لا يثبت نجاح CI موافقة PO، ولا يثبت وجود مسار في OpenAPI وجود Controller فعلي.

## حدود هذه الحزمة

- لا Backend code ضمن DOC-01.
- لا تعديل على قاعدة البيانات أو migrations.
- لا رفع صور أو اختيار مزود تخزين سحابي الآن.
- لا دمج PR التوثيق قبل موافقة PO على GitHub.
- لا force push ولا إعادة كتابة تاريخ الفروع.
