# Architectural Tension Identified

## Current Identity Model

T-07 describes:

- Stateless JWT.
- Refresh JWT.
- No server-side revocation.
- Direct token-based authentication.



---

## ADM-1 Future Model

ADM-1 proposes:

- Session storage.
- BFF architecture.
- Session invalidation.
- Refresh rotation.
- Revocation support.



---

## Review Observation

These are not contradictory designs.

However, they represent two different authentication architectures.

The project should explicitly define:

- Migration strategy.
- Compatibility approach.
- Refresh token behavior during migration.
- Session invalidation model.

Current documentation identifies the destination architecture but does not yet include a transition plan.
