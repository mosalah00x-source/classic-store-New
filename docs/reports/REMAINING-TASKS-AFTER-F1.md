# قائمة المتبقي بعد F1

**تاريخ التسجيل:** 2026-11-22  
**المرجع:** `docs/project-reference`  
**قاعدة الحالة:** جميع البنود أدناه مفتوحة. لا تعني هذه القائمة أن أي بند قد اكتمل أو قُبل.

## F — واجهة المتجر

| ID | البند | الوصف المختصر | الحالة |
|---|---|---|---|
| F1-R | قياس وميض الثيم | قياس Theme flash على Merge SHA وتوثيق أول إطار مرئي؛ لم يُقَس بعد | مفتوح |
| F2 | قرار حذف `.dn` من المرجع | قرار PO بشأن حذف شريط التنقل التجريبي `.dn` | مفتوح |
| F3 | Home storefront | Hero، تصنيفات، الأكثر مبيعاً، عرض ترويجي، وصل حديثاً، وخدمات | مفتوح |
| F4 | Catalog | الشارات، المفضلة، مطابقة الكروت والمسافات، وتوحيد لغة الأسماء | مفتوح |
| F5 | Product | المفضلة، الكمية، الملاحظات، CTA، وحسم السعر القديم حسب Variant | مفتوح |
| F6 | Locale | إزالة redirect الإجباري للعربية وترجمة النصوص الثابتة والتحقق من LTR | مفتوح |
| F7 | تكرار متغيرات الشعار | إزالة تكرار `--color-logo` و`--color-logo-inverted` من `globals.css` بعد الموافقة المطلوبة | مفتوح |
| F8 | catalog-api JSON | مراجعة/معالجة استجابة `catalog-api` بصيغة JSON | مفتوح |
| F9 | حساب العميل | تنفيذ واجهة/رحلة حساب العميل | مفتوح |
| F1-V | لقطات Home | التقاط `/ar` و`/en`؛ تنازل لقطات F1 لا يمتد إلى Home | مفتوح |

## ملاحظات الحالة

- F1 لم يُغلق بصريًا بالكامل: قياس الوميض ولقطات Home ما زالا مفتوحين.
- تنازل PO عن مصفوفة F1 الأصلية للقطات محدود بالنطاق المثبت في تعليق PR #26، ولا ينتقل تلقائيًا إلى F3 أو أي مهمة لاحقة.
- تبقى جميع B1–B7 وC1–C4 وQ1–Q5 مفتوحة كما هي، دون استنتاج اكتمالها من وجود API contract أو جداول أو وثائق.
